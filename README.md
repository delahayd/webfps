# La Dernière Porte
FPS rétro autonome, en français. Ouvrez `dist/index.html` dans un navigateur de bureau, ou servez `dist` avec `python3 -m http.server 8080 --directory dist`.

ZQSD/WASD : déplacer ; souris : viser et tirer ; flèches : tourner ; espace : tirer ; 1/2 : armes ; E : sceaux ; M : carte ; Échap : pause. Brisez les trois sceaux puis atteignez le portail au nord. La cache secrète se trouve dans le renfoncement ouest.

Rendu Canvas par raycasting, sprites procéduraux, sons Web Audio. Aucun moteur ou asset externe requis. Les polices Google sont facultatives. Version desktop ; commandes tactiles non incluses.
